Text layers

Every edit is a new possibility.

From data to something worth sharing.

1. Edit the sample data or import a CSV with a header row. Column A holds categories; the remaining columns hold numeric series.

2. Choose a chart, try a mood, and customize the type, palette, axes, labels, and layout. Scatter uses numeric X values; donut uses the first selected series.

3. Add text, drag it into place, then export the complete canvas.

Formulas: =SUM(B1:B6), =AVERAGE(C1:C3), =B1*1.2, =ROUND(B1/3,2). References count data rows only. Ranges ignore text; blank cells count as zero. Percent expects fractions (0.25 = 25%).

Shortcuts: Ctrl/Cmd+Z to undo, Ctrl/Cmd+Shift+Z to redo, Ctrl/Cmd+S to save. Paste tab-separated cells directly into the data table. Click a cell to inspect its raw formula.

Projects autosave in this browser. Save a .plotcraft.json file for a portable backup. This first release supports one chart per canvas, up to 200 rows, 12 columns, and 20 text layers.
